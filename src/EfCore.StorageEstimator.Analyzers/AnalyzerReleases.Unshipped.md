## Release 1.0.0

### New Rules

Rule ID | Category | Severity | Notes
--------|----------|----------|------
EFSA001 | Usage | Warning | StorageNavigationAttribute must target a type annotated with StorageEntityAttribute.
EFSA002 | Usage | Warning | StorageEntityAttribute expected row count must be greater than zero.
EFSA003 | Usage | Warning | StorageFieldAttribute fill rate must be between zero and one inclusive.
EFSA004 | Usage | Warning | StorageFieldAttribute AverageLength must be zero or greater.
EFSA005 | Usage | Warning | StorageNavigationAttribute average multiplicity must be greater than zero.
